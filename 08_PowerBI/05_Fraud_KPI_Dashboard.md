# Power BI — Step 5: Fraud KPI Dashboard

## Business Objective

Create an executive-level dashboard that provides a quick overview of transaction volume, fraud activity, fraud rate, and transaction amounts.

The KPI Dashboard is the first page of the Enterprise Banking Fraud Analytics Power BI report.

---

## Dashboard Title

Enterprise Banking Fraud Analytics — KPI Dashboard

---

## KPI Cards

The dashboard contains exactly 8 KPI cards.

### Row 1 — Transaction and Fraud Volume

1. Total Transactions
2. Fraud Transactions
3. Genuine Transactions
4. Fraud Rate

### Row 2 — Transaction Amount Analysis

5. Total Transaction Amount
6. Total Fraud Amount
7. Average Transaction Amount
8. Average Fraud Amount

---

## KPI Definitions

| KPI | Description |
|---|---|
| Total Transactions | Total number of transactions in the dataset |
| Fraud Transactions | Number of transactions identified as fraudulent |
| Genuine Transactions | Number of transactions identified as genuine |
| Fraud Rate | Percentage of transactions identified as fraudulent |
| Total Transaction Amount | Total monetary value of all transactions |
| Total Fraud Amount | Total monetary value associated with fraudulent transactions |
| Average Transaction Amount | Average value of all transactions |
| Average Fraud Amount | Average value of fraudulent transactions |

## Dashboard Design

The KPI cards are arranged in two rows.

### Row 1

Transaction volume and fraud identification metrics are displayed together.

### Row 2

Transaction value and fraud amount metrics are displayed together.

The KPI cards were aligned and formatted for consistent presentation.

Display units were set appropriately, including setting units to None where required for the formatted KPI values.

---

## Business Purpose

The KPI Dashboard provides an executive summary of the fraud environment.

It allows users to quickly understand:

- Overall transaction volume
- Fraud transaction volume
- Genuine transaction volume
- Overall fraud rate
- Total transaction value
- Total value associated with fraud
- Average transaction value
- Average fraud transaction value
