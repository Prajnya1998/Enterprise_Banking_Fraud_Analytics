# NumPy — Enterprise Banking Fraud Analytics

## Project Overview

This module applies NumPy to transaction and fraud analytics within the Enterprise Banking Fraud Analytics project.

The objective is to use NumPy for efficient numerical processing, statistical analysis, array operations, and fraud transaction analysis.

---

## Business Objective

The business team needs to understand transaction amount behavior and identify high-value fraudulent transactions.

NumPy is used to perform numerical analysis efficiently on transaction data.

---

## Files

### 01_NumPy_Basics.py

Introduces fundamental NumPy concepts:

- NumPy arrays
- Array size
- Array dimensions
- Array shape
- Data types
- Minimum value
- Maximum value
- Average value
- Total transaction value
- Basic filtering

### 02_Array_Operations.py

Demonstrates:

- Array indexing
- Array slicing
- Arithmetic operations
- Boolean filtering
- Range-based filtering
- Sorting
- Reverse sorting

### 03_Financial_Statistics.py

Performs financial statistical analysis using:

- Mean
- Median
- Standard deviation
- Variance
- Percentiles
- High-value transaction identification

### 04_Fraud_Amount_Analysis.py

Analyzes fraudulent transaction amounts using:

- Total fraud transactions
- Total fraud amount
- Average fraud amount
- Median fraud amount
- Minimum and maximum fraud amounts
- Fraud amount percentiles
- High-value fraud identification
