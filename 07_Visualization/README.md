# Visualization — Enterprise Banking Fraud Analytics

## Project Overview

This module contains visualization and statistical graphics developed for the Enterprise Banking Fraud Analytics project.

The visualizations help identify fraud patterns across transaction distribution, merchant categories, states, transaction hours, transaction amounts, and fraud risk patterns.

The module uses Matplotlib and Seaborn for business-focused fraud visualization.

---

## Visualization Files

### 01_Fraud_Distribution.py

Visualizes the distribution of:

- Genuine transactions
- Fraudulent transactions

### 02_Fraud_By_Category.py

Analyzes fraudulent transactions across merchant categories.

### 03_Fraud_By_State.py

Analyzes fraudulent transactions by U.S. state.

### 04_Fraud_By_Hour.py

Identifies fraud patterns across transaction hours.

### 05_Transaction_Amount_Histogram.py

Visualizes the distribution of transaction amounts.

---

# Seaborn Analysis

### 06_Seaborn_Fundamentals.py

Introduces Seaborn statistical visualization using:

- Bar plots
- Box plots
- Fraud distribution analysis
- Transaction amount comparison

### 07_Fraud_Heatmap.py

Creates a fraud heatmap showing the relationship between:

- Transaction hour
- Merchant category
- Fraud transaction volume

### 08_Fraud_Category_Visualization.py

Analyzes fraud categories using:

- Fraud transaction count
- Total fraud amount
- Top fraud categories

### 09_Fraud_Amount_Distribution.py

Analyzes transaction amount distributions between:

- Genuine transactions
- Fraudulent transactions

Uses:

- Histograms
- KDE
- Box plots
- 99th percentile visualization threshold

### 10_Seaborn_Fraud_Dashboard.py

Creates a consolidated Seaborn-based fraud visualization analysis covering:

- Top fraud categories
- Fraud by transaction hour
- Transaction amount distribution
- Top fraud states

---

## Business Objectives

The visualizations support the fraud analytics team by helping identify:

- Overall fraud distribution
- High-risk merchant categories
- High-risk states
- High-risk transaction hours
- Transaction amount patterns
- High-value fraudulent transactions
- Fraud concentration patterns
- Potential unusual transaction behavior
