# Visualization — Enterprise Banking Fraud Analytics

## Project Overview

This module contains visualizations developed for the Enterprise Banking Fraud Analytics project.

The visualizations help identify fraud patterns across transaction distribution, merchant categories, states, transaction hours, and transaction amounts.

---

## Visualization Files

### 01_Fraud_Distribution.py

Visualizes the distribution of:

- Genuine transactions
- Fraudulent transactions

### 02_Fraud_By_Category.py

Analyzes fraudulent transactions across merchant categories.

### 03_Fraud_By_State.py

Analyzes fraudulent transactions by U.S. state.

### 04_Fraud_By_Hour.py

Identifies fraud patterns across transaction hours.

### 05_Transaction_Amount_Histogram.py

Visualizes the distribution of transaction amounts.

---

## Business Objectives

The visualizations support the fraud analytics team by helping identify:

- Overall fraud distribution
- High-risk merchant categories
- High-risk states
- High-risk transaction hours
- Transaction amount patterns
- Potential unusual transaction behavior
