SQL development and analysis for the Enterprise Banking Fraud Analytics project.

This section contains SQL fundamentals, advanced SQL projects, fraud analysis queries, performance tuning, transactions, error handling, dynamic SQL, window functions and the end-to-end fraud analysis project.

## Structure

### 01_SQL_Fundamentals
Foundational SQL practice covering filtering, sorting, aggregate functions, joins, CTEs, subqueries, views, stored procedures, triggers, indexes, transactions, user-defined functions and window functions.

### 02_SQL_Advanced_Projects
Advanced SQL projects covering Projects 16–28, including performance tuning, dynamic SQL, error handling, transactions, MERGE, XML/JSON, advanced window functions and the end-to-end credit-card fraud analysis.
